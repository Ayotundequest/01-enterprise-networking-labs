## Overview

Welcome to my **Enterprise Networking Labs** repository.

This repository documents my practical networking journey as part of my **Enterprise Infrastructure & Cloud Engineering Programme (EICE)**.

The goal is to build a strong foundation in networking through hands-on labs, professional documentation, and real-world scenarios using **Cisco Networking Academy** and **Cisco Packet Tracer**.

Every lab in this repository follows a consistent engineering documentation standard and demonstrates the practical skills expected of an Infrastructure, Network, or Cloud Engineer.

---

## Objectives

- Build strong networking fundamentals.
- Gain hands-on experience with enterprise networking concepts.
- Document labs using professional engineering standards.
- Develop a portfolio suitable for Infrastructure, Cloud, and NHS technical roles.
